Troubleshooting

01. 소셜 로그인 후 Header 사용자 정보 미반영

소셜 로그인 직후 Header에 사용자 정보가 표시되지 않는 문제가 발생했습니다.

로그인 완료 시점과 Redux 상태가 변경되는 시점의 차이를 확인하고, 로그인 이후 사용자 정보를 다시 조회하여 Redux 상태를 갱신하도록 수정했습니다.

→ 로그인 직후에도 사용자 정보가 정상적으로 표시되도록 개선
02. 회원정보 수정 후 화면에 변경 내용 미반영

서버에서는 회원정보가 정상적으로 변경되었지만 Header와 화면에는 기존 정보가 표시되는 문제가 발생했습니다.

서버 데이터와 Redux 상태가 동기화되지 않는 것을 확인하고, 수정 성공 이후 Redux 상태를 갱신하도록 수정했습니다.

→ 회원정보 수정 결과가 화면에 즉시 반영되도록 개선
03. Next.js Hydration 오류

서버 렌더링 결과와 클라이언트 렌더링 결과가 달라 Hydration 오류가 발생했습니다.

서버와 클라이언트의 렌더링 시점 및 상태 흐름을 확인하고 클라이언트에서 처리해야 하는 로직을 분리하여 문제를 해결했습니다.

→ 정상적인 페이지 렌더링 구현
